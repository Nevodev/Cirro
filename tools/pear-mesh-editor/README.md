# Pear Mesh 封面预设工坊

直接在 Chrome / Edge 打开 `index.html`，无需启动服务或联网。文件中已内嵌着色器和原有控制点数据，单独复制这个 HTML 也能使用。

1. 导入图片（或拖进主画面），选择空白网格或以播放器预设为起点。
2. 「每边控制点」支持 2–16，点击「调整点数」会对 A / B 做双线性重采样，保留大体形状，可撤销。降低点数会减少细节。在「编辑 A / B」中拖动圆点；双击复位单点，方向键微调，Shift 约束拖动方向或加速键盘微调。也可以直接输入 X / Y。坐标与 Kotlin 相同，原点在左下，按行排列。
3. 在「预览」中拖动形变进度；播放时旋转和形变使用 App 的时间曲线。蓝色线是三轮细分后的实际网格，绿线是控制网格。缩小画布可编辑封面外的点。
4. 保存 JSON 可恢复图片、两个形态及参数。PNG 导出当前尺寸的方形封面，不带辅助线。浏览器会自动保存草稿，下载 JSON 更可靠。
5. Kotlin 导出 `MeshPreset`。默认「固定当前形状」会把当前 A/B 插值结果同时写到 from/to，适合静态封面；取消后保留两个形态。JSON 始终保留可编辑的 A/B。导出的预设不会自动写入 App。

模糊、旋转、暗部遮罩都作用于实时画面。默认模糊强度来自封面入口。渲染尺寸会影响模糊结果，定稿时使用目标尺寸。底色与 App 一样按原图 8 × 8 取样，透明图片先铺黑；导入时长边最多 2048 像素。9 × 9 预设在此作为方形封面使用，纹理采样范围为 0–1，不使用播放器横屏的裁切。

接入封面时，把导出的 `MeshPreset` 和参数写入 `PearMeshCoverPreset.kt`。网格生成入口从预设推导边长，支持每边 2–16 点；不要替换播放器预设。预设点位和参数参与本地封面的缓存标识，改动后自动重新生成。导出的文件头同时记录 `renderScale`、`blurMultiplier`、`scrimAlpha`、渲染时间和尺寸。图形后端及图片解码可能带来少量像素差异。

`sync_renderer.py` 从 Android 源码更新 HTML 的内嵌原有预设、着色器和模糊常量。修改这些源文件后，通过临时 Python 脚本调用此脚本再分发 HTML。它只更新标记间的生成数据，不改编辑器交互。网格细分与多阶段渲染顺序在 HTML 中实现；如 Android 渲染流程调整，需要一同核对。
