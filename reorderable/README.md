# Reorderable

Copied from Chrono's active Android fork in `reorderable/src/main`, retaining the
`sh.calvin.reorderable` package and upstream license notices. The nested upstream
project and generated build outputs are not part of this module.

The fork adds `canMoveItem` filtering for both drag swaps and automatic scrolling,
configurable settling animations, and velocity-driven drag rotation.

Cirro uses its existing version catalog and the app's SDK and Java configuration.
